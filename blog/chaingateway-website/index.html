chaingateway.io: die Website zur API

Marketing-Website und Einstieg für Entwickler: Was die API kann, was beim Server ankommt, welche Chains unterstützt werden, und wie man in Minuten startet.

DHDane Holzwarth13. November 20262 Min. LesezeitWebsiteAstroSEODeveloper Marketing
chaingateway.io

Ausgangslage

Eine API verkauft sich nicht über Versprechen, sondern über Klarheit: Was kann sie, wie sieht die Antwort aus, wie schnell bin ich live? Die Website von chaingateway.io muss Entwickler in Sekunden abholen und gleichzeitig bei Suchmaschinen gefunden werden.

Meine Rolle

Als Gründer von chaingateway.io habe ich auch die Website selbst gemacht. Alles aus einer Hand, bis auf das Logo, das es schon gab:

  • Konzept: Seitenstruktur, Inhalte und der Weg zum ersten API-Call
  • Design: Gestaltung auf Basis der bestehenden Marke
  • SEO-Konzept: Suchbegriffe, Seitenaufbau, technische Grundlagen
  • Umsetzung: Frontend, Backend und alles, was dazugehört

Lösung

  • Klarer Einstieg: was die API ist, für wen sie gedacht ist, und ein direkter Start
  • Echte Beispiele: was beim eigenen Server ankommt, wenn eine Zahlung eingeht
  • Anwendungsfälle, unterstützte Chains und Code-Beispiele in mehreren Sprachen
  • Gebaut mit Astro: schnell, statisch, gut für SEO
